# Marshall, Texas Weather

A responsive weather dashboard for Marshall, Texas, with a built-in weather forecast card game.

## Features

- Current weather conditions and forecast details
- Responsive layout for desktop and mobile screens
- Interactive forecast card game
- Refresh control for updating weather information

## Getting started

Open `index.html` in a modern web browser. This is a single-page project and does not require a build step.
